# 🔧 Fix Local MongoDB Connection

## 🚨 Current Issue

Your local server is failing with:
```
Error connecting to the database: MongoServerError: bad auth : Authentication failed.
```

The server is reading from `OSS-Management/.env` and using `process.env.URI` which contains invalid credentials.

## ✅ Quick Fix Steps

### Step 1: Check Your Current .env File

Your `.env` file is at: `OSS-Management/.env`

It likely has:
```env
URI="mongodb+srv://jadyn:290794@gamification.nwes9ze.mongodb.net/management?retryWrites=true&w=majority&appName=gamification"
```

These credentials are **invalid** (user doesn't exist or password is wrong).

### Step 2: Get Working Credentials

You have two options:

#### Option A: Use New Credentials (feb16)

If user `feb16` exists in MongoDB Atlas with password `KCILge3j9UtNunGF`:

Update your `.env` file:
```env
URI="mongodb+srv://feb16:KCILge3j9UtNunGF@gamification.nwes9ze.mongodb.net/management?retryWrites=true&w=majority&appName=gamification"
OSS_DOORWAY_DB_URI="mongodb+srv://feb16:KCILge3j9UtNunGF@gamification.nwes9ze.mongodb.net/?retryWrites=true&w=majority&appName=gamification"
```

#### Option B: Create New User in MongoDB Atlas

1. Go to: https://cloud.mongodb.com/ → Security → Database Access
2. Click "Add New Database User"
3. Username: `localdev` (or any name)
4. Password: Click "Autogenerate Secure Password" (or set your own)
5. **COPY THE PASSWORD** if autogenerated!
6. Role: "Read and write to any database"
7. Click "Add User"

Then update your `.env`:
```env
URI="mongodb+srv://localdev:YOUR_NEW_PASSWORD@gamification.nwes9ze.mongodb.net/management?retryWrites=true&w=majority&appName=gamification"
OSS_DOORWAY_DB_URI="mongodb+srv://localdev:YOUR_NEW_PASSWORD@gamification.nwes9ze.mongodb.net/?retryWrites=true&w=majority&appName=gamification"
```

### Step 3: Check IP Whitelist

Make sure your local IP is allowed:

1. Go to: MongoDB Atlas → Security → Network Access
2. Check if `0.0.0.0/0` is present (allows all IPs)
3. If not, click "Add IP Address" → Add `0.0.0.0/0` for testing

### Step 4: Test the Connection

After updating `.env`:

```bash
cd OSS-Management
node test-env-changes.js
```

Or just restart your server:
```bash
cd OSS-Management/backend
npm run start
```

You should see:
```
✅ Connected to MongoDB
```

Instead of:
```
❌ Error connecting to the database: bad auth
```

## 🔍 Debugging

If it still doesn't work:

1. **Verify user exists:**
   - MongoDB Atlas → Security → Database Access
   - Check if the user in your URI exists

2. **Verify password:**
   - Try changing the password in MongoDB Atlas
   - Update `.env` with new password

3. **Check IP whitelist:**
   - Make sure `0.0.0.0/0` is in Network Access

4. **Test connection string:**
   ```bash
   cd OSS-Management
   node test-env-changes.js
   ```
